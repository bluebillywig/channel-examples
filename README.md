# Blue Billywig Channel SDK Examples

Example apps demonstrating how to embed [Blue Billywig Channels](https://bluebillywig.github.io/channel/) in mobile apps.

## Examples

| Platform | Directory | Description |
|----------|-----------|-------------|
| **React Native** | [`react-native/`](./react-native) | Cross-platform app with inline and fullscreen player, Chromecast, navigation, and event handling |
| **SwiftUI** | [`swiftui/`](./swiftui) | iOS app with native player, Chromecast, and channel browsing |
| **Compose** | [`compose/`](./compose) | Android app with native player, Chromecast, and channel browsing |

## Getting Started

Each example app has its own README with build instructions. You'll need access to the Blue Billywig SDK packages — contact Blue Billywig to get set up.
